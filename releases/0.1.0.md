# Havo 0.1.0

Initial development version of the Haxo ventilation integration.

- Existing fan control with runtime detection of on/off, speed steps and preset-only capabilities.
- Independent temperature or adaptive humidity rules per ventilation, optional background flow, hysteresis and minimum run/rest periods.
- Dedicated outdoor sensors with weather fallback; explicit missing-data behavior.
- Persistent manual holds and immediate resume, native Home Assistant control/status entities.
- Embedded English/French panel with room navigation, permission checks, retained drafts and revision conflicts.
- Python and frontend tests, Hassfest/HACS workflows and reproducible bundled frontend.

This file prepares version 0.1.0; its presence does not mean a GitHub release has been published. Real-home calibration and hardware validation remain separate from automated tests and simulated Home Assistant checks.
