# Havo 0.3.1

Fixes outdated panel interfaces after a successful Havo update. Previous releases loaded the JavaScript from a fixed URL, allowing browsers to reuse an older cached bundle even after Home Assistant had loaded the updated integration.

The panel URL now includes a SHA-256 fingerprint of the installed bundle. Home Assistant recalculates it when the integration loads or reloads, outside its event loop. A changed file gets a new URL even when its size, timestamp or integration version stays the same.

If the bundle cannot be read, Havo logs a warning and preserves integration startup with the original URL. No ventilation settings or control behavior changes. The JavaScript bundle is unchanged from 0.3.0.

Validation: 155 Python tests and 48 panel tests, Ruff, TypeScript and the Node.js 24 build. Regression coverage checks the served content, stable URLs for unchanged files, new URLs after a content change and hashing outside the event loop. Publication is gated by CI, Hassfest and HACS validation.

Update through HACS or replace the integration folder, restart Home Assistant, then reload open browser pages. This does not replace an already loaded panel inside an open page.
