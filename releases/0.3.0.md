# Havo 0.3.0

Havo — **Home Assistant Ventilation Orchestrator** — now shares Halo’s room navigation and visual structure, with complete Spanish support and easier access to the Home Assistant sidebar.

- **Halo-aligned interface:** matching header, room rail, search, empty states, tabs, settings sections and save bar, using the active Home Assistant theme. Desktop keeps rooms beside their details; mobile uses successive views with a back button.
- **Room power shortcuts:** turn every fan in a room off when any is on, or turn them all on otherwise. Commands respect each fan’s capabilities and your permissions, run sequentially and stop on errors or changed assignments. Unsaved configuration blocks device commands; each fan keeps its own manual pause.
- **Home Assistant menu:** a 48 px button opens the host sidebar on narrow screens or when the sidebar is hidden in your preferences. It preserves the current view and unsaved settings, and respects kiosk mode and apps with their own sidebar.
- **Spanish throughout:** the panel, setup, native entities and command Activity now support Spanish and regional variants such as `es-ES` and `es-MX`. English and French remain supported. Custom names are preserved; unsupported languages fall back to English. Activity messages follow the server language, while the panel follows the user’s interface language.
- **English documentation:** a refreshed README with three screenshots from the isolated preview. The French README is removed; the interface still supports French. The standalone preview now includes English, French and Spanish sample data and several fan capabilities.

Existing room configurations, humidity thresholds, extraction time limits and manual pauses are preserved. On/off and preset-only fans never receive speed percentages. Requirements remain **Home Assistant 2026.10.0 or newer**.

Validation: **149 Python tests and 48 panel tests**, Ruff, TypeScript and a reproducible bundled panel built with Node.js 24. Local browser checks cover desktop and mobile layouts, translated labels and the native menu event in the isolated preview. The release workflow gates publication on Python/panel checks, Hassfest and HACS validation. These checks do not establish operation on physical fans.

Update through HACS or replace the `custom_components/havo` folder manually, then restart Home Assistant and reload the browser. Publishing this release does not install it or change your home’s configuration.
